# SE-05 — langkah owner dan batas bukti

Implementasi source SE-05 menyambungkan draft live; file BOMC belum disimpan otomatis. Jangan gunakan model/data klien untuk sesi ini. Source, hasil CI, service yang berjalan, konfigurasi Vercel dan penerimaan owner adalah identitas yang berbeda.

## Bukti otomatis yang dapat diulang

Jalankan helper di checkout Editor kandidat, dengan checkout Builder pasangan di sebelahnya:

```powershell
cd D:\projects\sibambo\sibambo-editor
.\tooling\testing\se05-acceptance.ps1
```

Helper memakai Python 3.12+ dan Bun yang sudah terpasang, memasang dependency dari lock ber-hash ke venv D:, menaruh browser/cache/temp/laporan di D:, lalu menjalankan service TLS loopback sintetis dan Editor production build. Tidak membuat akun, membuka tunnel, mengubah instalasi SketchUp atau melakukan deploy. Sertifikat dan kredensial yang dipakai hanya sintetis; bootstrap dihapus dan proses fixture dihentikan setelah tes. File `run.json` mencatat kedua SHA dan apakah checkout memiliki perubahan tracked. Laporan sintetis tidak membuktikan konfigurasi Auth0 nyata.

## Sesi owner gabungan yang masih harus dilakukan

Pemilik akun/operator: **Kais**, menggunakan tenant Auth0 nonproduksi dan registrasi Claude Code serta Codex yang sudah disetujui. Ikuti SOP SE-03 dan SE-04 untuk konfigurasi aktual; jangan tempel bearer, client secret, ticket, model atau teks permintaan ke issue/log/screenshot. Service harus satu proses dan Editor harus memakai HTTPS, service HTTPS/WSS, allowlist Origin persis dan BFF berkonfigurasi pasangan yang sama.

1. Buka Editor kandidat yang sudah terhubung ke service kandidat. Masuk sebagai owner, buka proyek sintetis, lalu **Hubungkan draft live**. Harapan: revisi 0 dan Viewer utama; tanpa viewer aktif, operasi tulis agent ditolak.
2. Hubungkan Claude Code lalu Codex dengan OAuth masing-masing. Cocokkan subject/client dan kode delapan karakter dari aplikasi agent, ketik kode di panel owner, lalu setujui izin. Harapan: client lain dengan subject manusia sama tidak mewarisi akses owner/grant. Uji pause dan revoke: tulis ditolak, model terakhir tetap terlihat.
3. Minta agent menambah satu ruang sintetis, lalu satu revisi. Harapan: satu kenaikan revisi per transaksi, modul muncul tanpa download/import BOMC, kamera tidak bergerak otomatis. Tekan **Bingkai draft** bila geometri berada di luar pandangan. Revisi tergambar menyamai revisi diterima sebelum tulis berikutnya dibolehkan.
4. Kirim permintaan revisi dari panel owner. Harapan: status read/addressed berubah, nomor revisi geometri tidak berubah hanya karena mengirim permintaan; addressed baru setelah revisi terkait tergambar. Tarik permintaan lain dan pastikan agent tidak ditawari item yang ditarik.
5. Putuskan jaringan tab melalui DevTools browser, lalu pulihkan. Harapan: status reconnect/galat dan TTL terlihat; model terakhir tetap ada; sesudah reconnect revisi cocok dan tidak ada dinding ganda. Buka tab owner kedua: yang terakhir terhubung menjadi Viewer utama, tab pertama pengikut. Tutup tab utama: tulis berhenti sampai viewer baru benar-benar terhubung dan ACK.
6. Coba New/Open/Close saat draft berubah. Pilih **Cancel**: model tetap. Coba tutup/reload tab: peringatan draft belum disimpan tampil. Jangan meninggalkan draft yang ingin dipertahankan. Save/reopen BOMC adalah SE-07, bukan bukti SE-05 ini.
7. Setelah bukti dicatat, **Keluar dari sesi owner** dan hentikan service/tunnel melalui SOP pemiliknya. Harapan: viewer terputus, tulis berhenti, ticket lama tidak dapat digunakan. Restart service bukan restore otomatis; epoch baru harus menghasilkan galat terlihat sambil tab mempertahankan model terakhir, sampai alur restore SE-08 tersedia.

Catat PASS/FAIL/NOT_RUN per langkah, waktu, kedua commit, URL Editor/service tanpa rahasia, versi client/browser serta kode galat yang terlihat. Jika gagal, simpan model terbuka dan laporkan langkah/kode tersebut. Jangan menganggap build, hash atau screenshot sebagai pengganti gate runtime nyata. SE-05 berstatus Review sampai gate live SE-03/04 dan langkah owner relevan diterima; SE-11 tetap gate Stable akhir.
