> **Status:** Cloud Complete → Review / Owner Acceptance. Dokumen ini hanya meminta Anda **menjalankan satu skrip, lalu membaca satu berkas hasil**. Tidak ada coding, tidak ada akun, tidak ada secret, tidak ada tunnel, tidak ada layanan berbayar, tidak ada merge atau deploy.

## 0. Ringkasan satu paragraf

SE-02 menambahkan "actor" proyek: satu objek di memori (hilang saat proses berhenti, tidak menulis ke disk) yang memastikan **hanya satu agen yang boleh menulis pada satu waktu**. Setiap penulis memegang *lease* bernomor (*fence*). Bila dua agen berebut, yang kedua mendapat penolakan yang jelas dan menyebut siapa penulis saat ini. Owner bisa **menjeda (pause)** proyek, **mencabut (revoke)** akses, atau **mengambil alih** peran penulis. Perubahan 1–8 modul diterapkan **atomik** (semua atau tidak sama sekali), dan permintaan yang sama dikirim ulang tidak diterapkan dua kali. Gate owner: **dua agen fiktif berebut, lalu Anda memeriksa bahwa penulis yang disebut, konflik yang eksplisit, pause, dan pengambilalihan sesuai harapan.** Semua data **fiktif** (rumah sintetis 8 × 6 m).

## 3. Persiapan (sekali saja)

**Langkah 3.1 — Buka PowerShell.** Tekan tombol Windows, ketik `PowerShell`, Enter.
*Hasil yang diharapkan:* jendela biru/hitam dengan prompt `PS C:\...>`.

**Langkah 3.2 — Periksa Git.**
```powershell

```
*Diharapkan:* `git version 2.x.x`. Jika "not recognized": pasang Git for Windows dari git-scm.com, **tutup dan buka PowerShell baru**, ulangi.

**Langkah 3.3 — Periksa Python.**
```powershell

```
*Diharapkan:* `Python 3.12.x` atau lebih tinggi (3.13 juga boleh). Jika lebih rendah/tidak ada: pasang dari python.org, centang **Add python.exe to PATH**, buka PowerShell baru, ulangi.

**Langkah 3.4 — Ambil kode ke folder kerja bersih.**
```powershell
cd $env:USERPROFILE

cd se02-check
git fetch origin ccr-ba8c6603-7aepyf
git checkout --detach FETCH_HEAD
```

*Diharapkan:* baris terakhir mencetak 40 karakter SHA. SHA ini boleh berbeda dari `1b6bef4f412865158d0badbf46fe89bc2beb42e3` **hanya jika** branch hanya bertambah commit dokumen. Skrip di Langkah 4 memastikannya; jika tidak cocok skrip berhenti dengan pesan jelas.

*Jika `git clone` meminta login atau gagal:* STOP, laporkan `NOT_RUN: tidak bisa clone` (jangan memasukkan token di mana pun).

## 8. Batasan yang jujur

- Helper hanya diuji pada Windows hosted CI, bukan di laptop Anda (hasil Anda yang pertama).
- Actor diuji **di dalam satu proses** dengan jam palsu dan thread; layanan jaringan sungguhan (SE-03), sinkronisasi WebSocket (SE-05), dan Editor (SE-06) belum ada.
- Aturan "kunci idempoten per modul" memakai turunan `sha256(idempotencyKey|moduleId)`: master v1.2 tidak tersedia di repo ini, jadi ini tafsiran SE-02 yang perlu dikonfirmasi saat review.
- Batas 4096 kunci idempoten per modul per epoch dari `ModuleStore` (BMB-008) tetap berlaku; setelah itu penulisan modul tersebut ditolak dengan `BUDGET_EXCEEDED` sampai epoch baru dibuka.
- Merge, deploy, tunnel, Auth0, dan layanan berbayar **tidak** dilakukan dan memerlukan persetujuan terpisah.
